# Test Plan
Generated by /plan-eng-review on 2026-08-11
Branch: main
Scope: M0 feasibility spike (open-sonus)

No web surfaces exist at M0, so the usual pages and routes section is replaced by the
harness and rig surfaces that M0 actually produces.

## Affected components

- `spike/harness/capture.py` — multi-channel continuous capture, 8 h runs
- `spike/harness/correlate.py` — cross-correlation offset estimation with confidence
- `spike/harness/report.py` — percentiles, threshold verdict, artefact index
- `spike/drivers/*` — throwaway per-protocol fan-out. Not tested by design (D5)

## Key interactions to verify

- Harness recovers a known injected offset across 0, 1, 5, 20, 100, 500 ms
- Harness recovers a negative offset (channel B leads channel A) with correct sign
- Harness tracks a slow drift from 0 to 50 ms over a simulated 8 h run
- Snapcast-only pair reads as sub-millisecond on real hardware before any opaque
  endpoint is measured
- Distance compensation: a mic moved 1 m further shifts the reading by ~2.9 ms
- Loopback reference channel yields absolute host-to-sound latency, not only
  speaker-to-speaker offset
- Correction events logged by drivers line up with artefact timestamps in the audio
- Probe bursts are recoverable when interleaved with music at the chosen level and
  spacing, and the probe's autocorrelation has a single unambiguous peak
- **Blind step injection:** an operator injects undocumented step changes into the
  timeline. The pipeline must detect every one. A missed blind step makes every
  endpoint result from that run inadmissible
- Artefact confirmation is blinded: the confirmer receives correction-event clips and
  random control clips without knowing which is which

## Edge cases

- Silent window in the source material — must report low confidence, not a noise peak
- Periodic or looping music — must not lock onto a false correlation peak
- Real offset larger than the search window — must report out of range, not a wrong peak
- Low SNR from room noise — confidence gate must fire
- Audio interface reports fewer channels than requested
- Sample rate mismatch between interface and expected rate
- **CRITICAL GAP** Loopback cable unplugged: reference channel silent for the whole run.
  No test, no handling, and the absolute latency numbers are silently meaningless.
  Fix: preflight check that every configured channel carries signal before the run arms
- **CRITICAL GAP** Disk exhaustion mid-run. No test, no handling, discovered when the
  run ends. Fix: preflight free-space check against the projected run size, plus a
  periodic check that aborts loudly with the partial data intact
- USB disconnect or xrun partway through an 8 h run
- Correlation locks onto a repeated beat and holds a smooth, tight, wrong lag series
- Real offset exceeds the search window, producing a confident wrong peak
- Partial run: rig died at hour 6. Report must state coverage, not extrapolate
- One endpoint never joined the group. Verdict must not silently average over it
- Endpoint drops and rejoins during the soak
- Host IP change on Wi-Fi roam: all pull endpoints lose the origin at once
- Endpoint puts itself to sleep during a quiet passage

## Critical paths

Ordered by M0 stage. Nothing in a later stage is built before the earlier one passes.

1. **M0a** Control authority inventory complete for every opaque endpoint. If no
   endpoint exposes an actuator finer than a coarse seek, stop.
2. Synthetic validation suite passes before any hardware run. Gate on this.
3. Snapcast control pair reads tight. Gate on this before measuring opaque endpoints.
4. **M0b** Two hours open-loop, then two hours with the crudest correction available.
   If drift is unarrestable or correction is necessarily coarse, stop.
5. **M0c** Full 8 h mixed-vendor soak produces: offset percentiles per endpoint pair,
   absolute tap-to-sound per protocol, correction frequency per endpoint, artefact clip
   index.
6. Report renders a pass or fail verdict against the committed decision table with no
   human judgement required to reach the verdict, and refuses to run against a decision
   table edited after data collection began.

## Explicitly not tested

- `spike/drivers/*` — throwaway code, deleted at M0 exit. CI must fail if M1 imports
  from this directory.
